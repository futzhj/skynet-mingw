# Skynet Manager

PyQt6 desktop process manager for the Windows build.

Run from the repository root:

```powershell
python -m pip install -r tools/skynet-manager/requirements.txt
python tools/skynet-manager/main.py
```

The packaged `SkynetManager.exe` expects `skynet.exe`, `examples/`, `cservice/`,
`lualib/`, and the other runtime files beside it.
